# Results

Campaign outputs live here. **This directory intentionally ships without any
result numbers**: every value is produced by actual simulations on your
machine, so nothing in this repository is a fabricated or illustrative result.

```text
results/
├── runs/                     # per-simulation working directories
│   ├── baseline/run_001/...  #   transcript.log, vsim_stdout.log, dump.vcd, *.ucdb
│   ├── ai/...
│   ├── train/...             #   one dir per RL worker process
│   └── <timestamp>_w00/ep_NNN/run_NNN/   # rollout episodes
├── baseline/                 # AI/ML OFF campaign
│   ├── history.json          #   one record per run (seed, test, coverage, times)
│   └── history.csv
├── ai/                       # AI/ML ON campaign (rollout)
│   ├── history.json
│   └── history.csv
└── comparison/               # generated by `aidvo compare`
    ├── comparison_report.md  #   side-by-side deliverable
    ├── coverage_progress.csv #   run, baseline_best_pct, ai_best_pct
    └── coverage_progress.png #   plotted trajectories (needs matplotlib)
```

## How to generate

```bat
sim\run_baseline.bat 40 1000       & rem AI off
sim\run_ai.bat ppo 2000 40 1000 95 & rem AI on (train + evaluate)
sim\compare.bat
```

or the equivalent CLI commands listed in `docs/05_aidvo_usage_guide.md`.

## Notes

* `history.json` records are append-safe: the file is rewritten after every
  run, so an interrupted campaign keeps everything completed so far.
* Delete `results/runs/` anytime - it only holds per-run working files.
* See `docs/07_aidvo_comparison_methodology.md` for metric definitions.
